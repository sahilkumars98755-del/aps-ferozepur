ARMY PUBLIC SCHOOL, FEROZEPUR — WEBSITE REDESIGN
=================================================

A complete modern redesign of www.apsferozepur.com, built from every page,
photo and document available on the original site.

HOW TO VIEW
-----------
1. Unzip this folder anywhere.
2. Double-click index.html (or open it in any modern browser).
3. The site is fully self-contained — HTML, CSS, JavaScript, 179 photos
   and 25 downloadable PDFs. No build step or server needed.
   (The Google Map on the Contact page and external links need internet.)

WHAT'S INSIDE
-------------
index.html            Home — hero, announcements ticker, quick actions,
                      vision/mission, stats, facilities, achievements, gallery
about.html            History timeline, mandatory public disclosure,
                      Principal's desk, vision & aims
admission.html        Admission procedures, age criteria, Class XI stream
                      criteria and subject tables, documents required
infrastructure.html   All 15 facilities with photos (labs, library, smart
                      classes, herbal garden, science park, NCC, sports...)
gallery.html          Every photo from the school archive (179), with
                      category filters and a full-screen lightbox
news.html             Achievements 2023-24, NCC activities, seminars &
                      workshops, olympiad medals, and the news archive
downloads.html        TC download, class-wise homework (I-XII), admission
                      forms, staff vacancy forms (LSB-2025), newsletter,
                      useful links (CBSE, NCERT, online fees)
contact.html          Address, phone, emails, feedback form, Google Map

css/style.css         Complete design system (army olive & brass theme)
js/main.js            Nav, ticker, scroll reveals, counters, gallery
                      filters, lightbox, back-to-top
images/               All 179 photographs + school crest, recovered from
                      the original website
download/             All 25 PDFs from the original website
favicon.png           School crest favicon

DESIGN NOTES
------------
- Responsive: works on phones, tablets and desktops (hamburger menu).
- Accessibility: semantic HTML, alt text, keyboard-friendly lightbox.
- The feedback form is a front-end demo (no backend on a static site) —
  it notes this to users and directs them to the school email/phone.
- To deploy: upload the entire folder to any static web host
  (the school's existing hosting, GitHub Pages, Netlify, etc.) and
  make index.html the default document.

CONTENT SOURCE
--------------
All text, images and documents were recovered from the original
apsferozepur.com pages (Home, About Us, School Info, Admission,
Infrastructure, School Update, Download Section, Useful Links,
Feedback and Contact). Nothing was invented — only reorganised.
